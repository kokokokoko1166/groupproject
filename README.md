# 學生行為事件與輔導紀錄整理

> 老師當下 10 秒記下學生事件，事後一鍵整理成正式的輔導紀錄。

## 專題簡介

我們對 13 位國小老師做了問卷調查，發現「學生秩序、班級經營、突發狀況」是老師最常提到的工作困擾，而「學生行為事件與輔導紀錄整理」也是老師最希望 AI 教師助手提供的功能（7/13 人，第一名）。

本專題製作一個網頁工具，讓老師：

1. **快速記錄**：點座號、點事件類型，10 秒內記下一筆事件；也可以用語音說或拍照上傳，自動轉成文字，老師確認後送出
2. **紀錄列表**：依學生、日期、類型篩選，可修改或刪除
3. **產生正式紀錄**：自動整理成正式輔導紀錄，老師確認後列印或複製
4. **統計**：最常發生的事件、最容易出狀況的節次

## 系統架構

| 層級 | 技術 | 說明 |
|---|---|---|
| 前端網頁 | HTML / CSS / JavaScript，放在 GitHub Pages | 老師操作的畫面 |
| API | Google Apps Script | 網頁與試算表之間的橋樑 |
| 資料庫 | Google 試算表 | 學生名單、事件類型、事件紀錄 |

```
├── index.html          快速記錄
├── records.html        紀錄列表
├── report.html         產生正式紀錄
├── stats.html          統計
├── css/style.css       共用樣式
├── js/storage.js       讀寫資料（目前使用假資料）
├── apps-script/Code.gs 後台程式（貼到 Google 試算表的 Apps Script）
└── docs/               問卷分析、任務清單、報告
```

## 隱私原則

- 網頁只顯示座號，不顯示學生姓名
- 開發與展示一律使用假資料
- 通行碼、API 金鑰不可放進 GitHub（Gemini 金鑰放在 Apps Script 指令碼屬性）
- Gemini 免費額度的內容會被 Google 用於改進產品，只能送假資料
