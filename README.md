# 學生行為事件與輔導紀錄整理

> 為因應教育現場的多種變化，除了立即記下關鍵行為外，事後更需要有工具可協助一鍵整理成正式的輔導紀錄。

## 專題簡介

我們以國小老師為對象進行問卷調查，總共蒐集13位老師意見。其中，多數都因「學生秩序、班級經營、突發狀況」為主要的工作困擾，而「學生行為事件與輔導紀錄整理」也是老師最希望AI教師助手提供的功能（7/13 人，第一名）。

老師解決完學生事件後常常沒空逐字記錄，所以本專題想讓老師用**拍照、說話或隨手打字**記下事件，再由 **AI 整理成正式的紀錄文字**，確認後送出即可。

## 功能

1. **快速記錄**：選學生 → 選事件類型（可交給AI判斷）→ 用拍照、語音或打字描述 → AI整理成正式文字 → 老師確認後送出
2. **紀錄列表**：依學生、事件篩選，保留AI整理後的文字與原始輸入，可刪除
3. **產生正式紀錄**：選取學生與日期，自動整理成輔導紀錄；AI可撰寫「教師觀察與後續輔導建議」
4. **統計**：事件類型、最常發生的節次、紀錄最多的學生、處理方式

## 隱私原則

- 展示用的學生姓名皆為虛構
- 送給 AI 前會自動移除學生姓名，AI 只看到「該生」；照片只用來辨識，不會儲存
- AI 整理的文字一律由老師確認後才送出
- API 金鑰只存在使用者自己的瀏覽器，**不可放進 GitHub**
- Gemini 免費方案的內容可能被 Google 用於改進產品，因此只能使用假資料；正式使用需改用付費方案或學校核可的服務
